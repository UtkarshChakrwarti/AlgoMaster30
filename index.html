Day 01: Arrays & Hashing

O(1) Lookups, State Deduplication, and Anagram Invariants

01/30
📣 Coach's Daily Briefing
Today we start with the simplest trade in computer science: spending memory to kill nested loops. If you catch yourself scanning an array twice just to see if a match exists, stop and reach for a hash map. The mental habit today is single-pass thinking—don't look forward, query what you've already seen behind you.

The Naive Trap:

A brute-force approach compares every pair in O(N²), which wastes time re-scanning seen elements.

2
The Key Insight:

Instead, as we scan once, we query our hash map for (target - nums[i]) before inserting nums[i].

3
The Complexity Guarantee:

This guarantees single-pass O(N) time and O(N) space, avoiding duplicate self-matching.
